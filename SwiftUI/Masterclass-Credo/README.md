# SwiftUI Masterclass — Credo Academy

[Credo Academy](https://credo.academy)의 SwiftUI Masterclass(강사: Robert Petras) 학습 자료 아카이브.

> ⚠️ **출처/저작권**: `Gradient-Text` 등 일부 프로젝트는 Robert Petras / Credo Academy 원본 자료입니다. 학습용 보관 목적이며 상업적 재배포 금지. 원본은 [credo.academy](https://credo.academy) 참고.

## 📂 프로젝트

| 폴더 | 내용 |
|------|------|
| `HelloWorld/` | SwiftUI 첫 프로젝트 (기본 스캐폴드, 강의 시작점) |
| `Gradient-Text/` | `LinearGradient` + `mask`로 그라디언트 텍스트 만들기 (by Robert Petras, credo.academy) |
| `AsyncImage/` | `AsyncImage` 사용법 워크샵. `Completed/`(완성본) + `Resources/`(자료) + `Students/`(실습용) 구조 |
| `SwiftUI-Link/` | `Link` 뷰로 외부 URL 열기 |

## 🛠 빌드

각 폴더의 `*.xcodeproj` 열고 ⌘R. iOS 시뮬레이터.
