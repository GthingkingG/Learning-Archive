# Apple SwiftUI Tutorials

[Apple Developer SwiftUI Tutorials](https://developer.apple.com/tutorials/swiftui)의 챕터별 샘플 프로젝트 학습 아카이브.

> ⚠️ **출처/저작권**: 모든 챕터 코드는 **Apple Inc.** 의 공식 SwiftUI Tutorials 다운로드 자료입니다. 학습용 보관 목적이며, 각 프로젝트 내 `LICENSE.txt` (Apple 표준 사용권 라이선스) 따름. 상업적 재배포 금지.

## 📂 챕터

| 챕터 | 학습 주제 |
|------|---------|
| `Landmarks/` | Multi-platform 앱 (iOS + macOS + watchOS) — 공식 튜토리얼의 메인 |
| `AnimatingViewsAndTransitions/` | 애니메이션 / 트랜지션 |
| `ComposingComplexInterfaces/` | 복잡한 인터페이스 조립 |
| `CreatingAmacOSApp/` | macOS 앱 생성 |
| `CreatingAwatchOSApp/` | watchOS 앱 생성 |
| `DrawingPathsAndShapes/` | Path / Shape 드로잉 |
| `HandlingUserInput/` | 사용자 입력 처리 |
| `InterfacingWithUIKit/` | UIKit과의 상호 작용 |
| `WorkingWithUIControls/` | UIControl 사용 |

## 🛠 빌드

각 챕터 내 `*.xcodeproj` 열고 ⌘R. 챕터별 README.md 또는 Apple 공식 튜토리얼 페이지 참고.

## 📚 원본 다운로드

각 챕터 페이지의 "Download Project Files" 버튼:
- 예: https://developer.apple.com/tutorials/swiftui/creating-and-combining-views

본 디렉토리는 학습 진행에 따라 본인 수정/실험 코드를 누적할 수 있어 원본과 다소 차이가 있을 수 있음.
