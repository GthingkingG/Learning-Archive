## 🛠️ Principles
- **Documentation as Code**: 모든 이론 학습은 마크다운 파일로 기록하여 코드와 함께 관리합니다.
- **Troubleshooting**: 에러 해결 과정은 생략하지 않고 상세히 기록합니다.
- **Consistency**: 작은 기록이라도 꾸준히 업데이트하여 성장의 궤적을 남깁니다.
